# 🔧 Mecânica Pneu Queimado

Site institucional desenvolvido para uma oficina mecânica, com o objetivo de apresentar seus serviços, destacar suas especialidades e facilitar o contato com os clientes.

## 📌 Sobre o projeto

O site possui um design moderno, com tema escuro, detalhes em vermelho e layout responsivo, proporcionando uma experiência visual profissional e facilitando a navegação em computadores e dispositivos móveis.

## ✨ Funcionalidades

- 🏠 Apresentação da oficina.
- 🔧 Divulgação dos serviços mecânicos oferecidos.
- 🚗 Exibição de produtos e especialidades.
- 📩 Formulário de contato integrado ao Google Forms.
- 📱 Layout responsivo para diferentes tamanhos de tela.
- 📍 Seção com endereço e localização.
- 💬 Botão flutuante para contato pelo WhatsApp.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas.
- **CSS3** — estilização e responsividade.
- **JavaScript** — interatividade e funcionalidades.
- **Google Forms** — recebimento das mensagens enviadas pelo formulário.
- **Font Awesome** — ícones utilizados na interface.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Mantenha a estrutura das pastas.
3. Abra o arquivo `index.html` no navegador.
4. Navegue pelas seções e teste as funcionalidades do site.

## 🎯 Objetivo

Desenvolver uma presença digital para a oficina, apresentando seus serviços de forma organizada e oferecendo aos clientes canais simples de comunicação e solicitação de informações.
